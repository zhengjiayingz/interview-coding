Please check the code challenge for the candidate 郑嘉颖

需求：实现一个通用的学习培训申请功能
 
描述：申请的课程可以支持线上学习和线下学习，线下学习需要到指定的培训地点，培训地点可能有多个并且有人数限制， 想一下还有哪些字段是需要补充的。
1.	查看课程信息列表，选择一个课程报名，在课程开始前一天可修改部分报名信息，课程信息可用mock数据展示
可以不用做课程信息创建管理等功能。
2.	个人信息，姓名，联系电话，地址等，
3.	报名的时候线下学习需要选择培训地点和时间。
4.	填写完信息之后可以预览填写信息是否有问题，有问题可以跳转到对应的表单修改。
5.	组件需要可复用，报名信息除了基本信息，如果有特殊活动需要增加填写内容可以在第3点填写培训地点和时间这一步填写信息。
6.	要有一个统计报表看学员申请情况(可使用mock data)
7. 组件需要单元测试
 All the code challenges should be implemented using any of below tools:
1.	TypeScript
2.	Sveltekit
3.	Tailwindcss
4.	Vitest
5.	Apache Echarts
Note:
•	React / Vue / Angular should NOT be used but other tiny libraries are allowed to achieve the goal in code challenge.
